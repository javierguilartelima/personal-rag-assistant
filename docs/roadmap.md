# Product Roadmap

## Product Goal

Build a privacy-aware personal AI assistant that helps people turn knowledge, goals, and personal context into useful decisions, concrete actions, and measurable progress.

The system should become more useful over time without trapping the user in one AI provider, one device, or one closed data format.

## Guiding Principles

- Useful before impressive

- Privacy by design

- Source-grounded answers

- User-controlled memory

- Modular and replaceable components

- Provider-independent AI layer

- Local and offline capabilities where practical

- User-owned and exportable data

- Simple experience for non-technical users

- Build features only when they provide clear value

## Now

Current focus:

- public/private knowledge separation

- local document loading

- metadata-preserving chunking

- keyword retrieval

- semantic retrieval

- automated privacy tests

- reproducible local development environment

## Next

Near-term milestones:

1. Generate grounded answers from retrieved chunks

2. Show sources used in every answer

3. Distinguish retrieved facts from inference

4. Add a provider-independent LLM interface

5. Connect one initial online AI provider

6. Create a simple local web interface

7. Add retrieval-quality tests

8. Improve document ingestion and metadata

## Later

Capabilities to add when justified by real usage:

- controlled long-term memory

- user-editable preferences and goals

- Obsidian integration

- tasks, reminders, and follow-up

- Gmail and Calendar tools

- local model support

- automatic online/offline routing

- mobile-friendly PWA

- encrypted backups and synchronization

- data export and import

- multi-user isolation

- shared knowledge spaces

- cost-aware model routing
